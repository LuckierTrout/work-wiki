## Findings

All findings below blocked acceptance at the reviewed SHA. Source line references are snapshot evidence for that revision and may no longer match the active remediation worktree.

### Release and integration boundary — fix now

- **The signed-in Workbench is not buildable or runnable.** `LintCanvas` imports runtime values from `workbench-lint.ts`, which imports `lint-checks.ts` and the storage stack. This chain pulls the Node-only `node:fs/promises` and `node:path` modules into the client bundle (`src/components/workbench/LintCanvas.tsx:7-11`, `src/lib/workbench-lint.ts:6-10`). `pnpm build` fails on that exact import trace, and a clean Playwright run fails every signed-in Workbench journey for the same reason. Disposition: **fix now**.
- **The full repository suite rejects Epic 5's data-version integration.** `graph-insight-dismissals.ts` and `review-queue.ts` call `bumpDataVersion` directly (`src/lib/graph-insight-dismissals.ts:105-109`, `src/lib/review-queue.ts:160-164`), violating the existing test-enforced single-site writer contract. `pnpm test` finished with 6,496 passing tests and one failure in `workbench-data-version.test.ts`. Disposition: **fix now**.

### Graph, Relevance, and Insights — fix now

- **Reduced-motion Graph layout collapses uncached nodes.** Every new node receives the same cached origin and ForceAtlas2 is skipped (`src/components/workbench/GraphCanvas.tsx:140-180`), so a first load or post-ingest refresh can render all nodes at one point. This violates Story 5.4's reduced-motion layout behavior. Disposition: **fix now**.
- **Fit uses raw layout coordinates as Sigma camera state.** Sigma normalizes graph coordinates into camera space, but the implementation passes the raw bounding-box midpoint and `span / 80` directly to `camera.animate` (`src/components/workbench/GraphCanvas.tsx:298-326`). The control is not a reliable fit-to-all-nodes operation. Disposition: **fix now**.
- **Identical topology can produce different communities.** Louvain runs with its package defaults (`randomWalk: true`, `rng: Math.random`) at `src/lib/graph-louvain.ts:92-107`. Repeated local runs on the same eight-node ring produced two different assignments. Community colors, sparse IDs, bridge fingerprints, and durable dismissals can therefore change without a wiki-structure change. Disposition: **fix now**.
- **The legend warning threshold diverges from the declared contract.** `warn` is gated on three pages (`src/lib/graph-louvain.ts:125-137`), although the three-page floor belongs to Sparse Insights, not the legend's "Cohesion < 0.15" warning. Its test is vacuous because three disconnected nodes become singleton communities (`src/lib/__tests__/graph-louvain.test.ts:28-37`). Disposition: **fix now**.
- **Graph and Chat do not share one wikilink interpretation.** Graph normalizes path-like and human-readable wikilinks through `extractAllInternalTargets`, while Chat's private parser requires an exact raw slug (`src/lib/links.ts:40-77`, `src/lib/wiki-retrieve.ts:377-410`). The same page pair can receive different direct-link evidence. Disposition: **fix now**.
- **Deep Research does not read the active Wiki's Purpose.** `buildResearchPrefill` reads a legacy page named `purpose` through `readWikiPage` (`src/lib/research-prefill.ts:19-39`), while per-Wiki Purpose is resolved through the current Wiki registry/profile. The Graph route also silently stops prefilling after 12 eligible Insights (`src/app/api/graph/workbench/route.ts:25-43`). Disposition: **fix now**.
- **Insight dismissal durability is weaker than promised.** The first write uses a check-then-unconditional-write sequence across Worker isolates; malformed JSON becomes an empty store and is overwritten by the next mutation; dismissal fingerprints omit some material topology changes (`src/lib/graph-insight-dismissals.ts:40-103`, `src/lib/graph-surprise.ts:131-198`). Disposition: **fix now**.

### Workbench Lint and mechanical fixes — fix now

- **Workbench Lint exposes a broader write than Story 5.9 permits.** The allowlist treats every `broken-link` as mechanically fixable (`src/lib/workbench-lint.ts:29-34`), and the delegated legacy fixer removes both Markdown links and wikilinks (`src/lib/lint-fix.ts:407-465`). The declared Workbench class is specifically dangling `[[slug]]` after delete. Disposition: **fix now**.
- **Stale-index repair bypasses the lifecycle/history contract and can lose concurrent index updates.** It reads the index before the final writer's lock, calls `updateIndex` directly, and never records Page history or performs the normal lifecycle data-version tail (`src/lib/lint-fix.ts:89-131`). Disposition: **fix now**.
- **Auto-fix does not carry a content precondition or revalidate the reported issue.** The route accepts client-supplied type/slug/target, and link rewrites operate on whatever bytes exist when the request lands (`src/app/api/lint/workbench-fix/route.ts:18-34`, `src/lib/lint-fix.ts:423-465,477-519`). A stale report can overwrite a newer page edit; direct calls can rewrite a target that is no longer a valid lint issue. Disposition: **fix now**.
- **Regex rewrites alter more than the requested navigation link.** They scan raw YAML/code/examples, and renamed wikilinks drop `#section` fragments (`src/lib/lint-fix.ts:428-441,490-500`). Disposition: **fix now**.
- **Semantic Lint recreates a second gap list instead of pointing to Graph Insights.** `missing-concept-page` and `incomplete-coverage` are returned as ordinary Lint rows whose only action docks their Page (`src/lib/workbench-lint.ts:47-52,113-127`, `src/components/workbench/LintCanvas.tsx:101-123`). This contradicts the declared no-second-gap-product boundary. Disposition: **fix now**, with the exact UI mapping requiring product reconciliation.
- **Orphan and Preview edge behavior diverges.** Self-links count as inbound, renamed aliases do not count toward their canonical target, and a disputed page opened from Files receives `disputed: true` from the API but the column renders the marker only for `selection.kind === "page"` (`src/lib/workbench-lint.ts:58-83`, `src/components/workbench/PreviewColumn.tsx:1118-1139`). Disposition: **fix now**.

### Review queue and ingest integration — fix now

- **Successful ingest does not reliably produce persistent Review items.** The queued Worker hook logs and discards load/store failures without durable retry (`src/app/api/tasks/run/route.ts:559-579`); an earlier post-compile failure can make the retry return `skipped` before the hook (`src/app/api/tasks/run/route.ts:464-478`); author-only tasks miss `actionOwner`; and the shared inline/off-Worker path never invokes Review enqueue (`src/lib/ingest-async.ts:46-93`). Disposition: **fix now**.
- **Review-created pages are written ownerless.** The generated Markdown has no owner frontmatter (`src/lib/review-queue.ts:220-236`), while the lifecycle derives the write tenant from frontmatter and falls back to frozen default tenant `yopedia` (`src/lib/lifecycle.ts:208-217`). Disposition: **fix now**.
- **Stored `wikiId` is ignored by reads, deduplication, actions, and UI.** Tenant-global listing mixes cards, same-title drafts suppress one another across Wikis, and Create Page acts against the currently addressable page store rather than the card's Wiki context (`src/lib/review-queue.ts:168-249,305-335`, `src/components/workbench/ReviewCanvas.tsx:25-56`). Disposition: **fix now**; the product must confirm whether the intended queue view is current-Wiki or explicitly tenant-wide.
- **Create Page has recoverability and collision gaps.** Slug choice occurs before the claim, the queue marks `created` before the page write, two items can choose the same slug, and rollback restores only status while leaving the proposed path/slug (`src/lib/review-queue.ts:194-248`). Disposition: **fix now**.
- **Queue limits and corruption handling can report successful persistence when no item was stored.** At 500 pending items, the new item is sliced off but returned as created; malformed JSON is treated as empty; and first creation is not conditional across Worker isolates (`src/lib/review-queue.ts:57-84,124-165,305-335`). Disposition: **fix now**.

### Cross-cutting verification and maintainability — fix now

- **The declared 662-test Epic suite is strong at pure/kernel behavior but weak at the delivered browser boundaries.** It does not instantiate a non-empty Sigma/WebGL graph, exercise node click/hover/zoom/Fit/highlighting, run Lint/Review success flows through their HTTP routes, prove Review Create Page rollback/collision behavior, or execute the confirm-to-filled Research transition. Several adoption checks read component source text rather than rendering it (`src/lib/__tests__/workbench-chrome.test.ts:299-336`, `src/lib/__tests__/workbench-preview.test.ts:1056-1065`). Disposition: **fix now**.
- **Badge and mounted-canvas state have stale-response windows.** A ReviewCanvas mutation can update the badge while an older Workbench fetch remains eligible to overwrite it (`src/components/workbench/Workbench.tsx:374-414,1618-1622`). Graph, Lint, and Research also handle loading failures, request errors, and in-flight invalidation inconsistently. Disposition: **fix now**.
- **The epic concentrated too much delivery and verification in one revision.** One commit changed 61 files; `GraphCanvas.tsx` added 520 lines and combines API state, package loading, layout, Sigma lifecycle, persistence, interaction reducers, Preview routing, dismissal, and Research actions. This is a maintainability/process finding, not proof that every large file is wrong. Disposition: **fix now** as a delivery and decomposition lesson.

### Checked-clean areas — accept as-is

- The exact four-signal weights are implemented and focused tests pin shared-Source precedence, unrelated score zero, and Chat source evidence (`src/lib/graph-relevance.ts`, `src/lib/__tests__/graph-relevance.test.ts`, `src/lib/__tests__/wiki-retrieve.test.ts`).
- Graph, Lint, Review, and dismissal routes are owner-gated; persistent mutations refuse read-only mode.
- The queued Worker path does not enqueue Review for a failed or initially skipped compile.
- Review exposes only Deep Research, Create Page, and Skip; Skip makes no wiki write.
- Graph and Review confirmations create a Research draft through `/api/research`; Epic 5 code does not invoke the web-run route.
- Frozen runtime identifiers, `SCHEMA.md`, `llm-wiki.md`, protected workflow files, and the deferred-work ledger were not changed by the retrospective.
