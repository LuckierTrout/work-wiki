# Reconciliation: PRODUCT.md

**Input:** `PRODUCT.md` (brand / product-context)
**Intent:** Lock brand register, positioning, tone, audience, and principles for work-wiki as a collective second brain — commons-first, lab-with-receipts, not RAG.

## What the PRD / addendum captured

- **Not RAG; compile and accumulate.** Vision and Non-Goals: cited Pages, revisions, disputed state, staleness/Lint, agent-readable Schema. Durable knowledge over transient chat.
- **Agents maintain, humans steer (HITL).** Ingest synthesizes; Review queue + Chat + Todo approve/reject are the human gates. Provenance via immutable Sources, `sources: []`, Log, Activity.
- **Anti-refs that still apply to v1 UI** (addendum Aesthetic note): no generic AI landing-page costume, no fake terminal skin, no metric dashboard as home.
- **Commons-first / public research lab / observer audience / paid vaults.** Captured as **v1 rejection**: Non-Goals, Non-Users, MVP out-of-scope (shared vaults, billing, observer dashboards). Addendum table: commons-first multi-user wiki deferred because a public lab would leak meeting Sources.
- **v1 feel substitute:** nashsu Workbench density (tree / chat / preview / queue), private compiled Wiki, one operator.

## Gaps

Ideas in PRODUCT.md that the PRD dropped, diluted, or explicitly set aside.

### Highest-signal (actionable)

1. **Tone / voice (dropped).** PRODUCT: precise, evidence-rich, curious, unsentimental; short direct copy; explain what the journal proves without overclaiming. PRD has no voice contract. Addendum kept only anti-refs, not this positive register. UX copy and empty states will default to generic SaaS or nashsu-neutral without it.

2. **“Humans discuss” diluted to Review cards.** PRODUCT principle: humans steer via *discussion*; agents synthesize and reconcile. PRD maps this to a closed Review set (Create Page / Deep Research / Skip) plus Chat. No Page-level discussion thread, comments, or talk-page. Steering is ticket-like, not conversational.

3. **Confidence as a visible accumulation attribute (dropped).** PRODUCT purpose lists confidence alongside citations, revisions, expiry, and discussion. PRD has disputed + Lint staleness/expiry, not a confidence signal on Pages.

4. **Editorial / magazine anti-ref (dropped).** PRODUCT forbids editorial affectation that makes the product feel like a magazine instead of a working lab. Addendum aesthetic note lists three anti-refs and omits this one — risk of over-designed prose in Preview/Chat chrome.

### Rejected in addendum (not misses)

- **Commons-first shared wiki, public research-lab positioning, observer/builder audience, vault-as-lens + paid private space.** **rejected (in addendum)** — private job tool; revisit as a later product.
- **Public “show the trail” / experiment-with-receipts** (issues, commits, agent roles, visible journal for outsiders). **rejected (in addendum)** as public-lab UI. Private inspectability (Activity, Log, observability NFR) is the remnant; agent-role/journal-as-branded-surface is not a v1 requirement.
